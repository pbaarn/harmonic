# Harmonic Canvas 🎵

An interactive harmonic visualization and chord progression workbench for musicians, composers, and theory enthusiasts.

## Live Demo

Hosted on GitHub Pages: [https://pbaarn.github.io/harmonic/](https://pbaarn.github.io/harmonic/)

## Features

- **Interactive Fretboard & Keyboard**: Visualize notes, intervals, degrees, and custom chord voicings across the instrument.
- **Harmonic Interval Map**: Discover chord structures based on target notes, note degree roles, and chord families.
- **Audio Synthesizer & Sequencer**: Audition chords and progressions live with web audio synthesis.
- **Custom Progression Builder**: Create, loop, and export custom harmonic progressions.

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build

# Deploy to GitHub Pages manually
npm run deploy
```
